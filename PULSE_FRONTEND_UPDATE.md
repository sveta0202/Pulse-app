# Обновление PULSE: пульс и примеры ЭМГ

Распакуйте архив в корень существующего `Pulse-app` с заменой совпадающих файлов. Архив не содержит `weights/pulse.pt` и не заменяет Dockerfile или Railway-конфигурацию. Ваши веса остаются на месте.

Для локальной проверки перезапустите `server.py`, затем обновите страницу PULSE. В «Лаборатории» нажмите «Запись 01» или любую другую: загрузка сигнала и прогноз идут одним действием. Ручная загрузка по-прежнему доступна.

## GitHub и Railway

Перед пушем убедитесь, что эти пять записей можно размещать на публичном сайте: посетитель сможет получить исходные `.npy` через `/examples/01` … `/examples/05`. Затем добавьте изменённые файлы в существующий GitHub-репозиторий:

```powershell
git add -- .gitignore server.py static/index.html static/examples README.md PULSE_FRONTEND_UPDATE.md
git diff --cached --name-only
git commit -m "Loop PULSE animation and add EMG examples"
git push
```

Dockerfile уже копирует каталог `static/`, менять его не нужно. Проверьте новый деплой на Railway, откройте `/healthz` и затем запустите один пример с публичной страницы.
